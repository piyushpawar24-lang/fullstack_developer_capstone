# IBM Full Stack Django and React Dealership Application

## Repository Name
`dealership-project`

## Project Name
IBM Full Stack Django and React Dealership Application

## Project Description
This project is a full-stack car dealership application developed using Django and React. It allows users to browse car dealerships, view dealer details, register and log in, and submit reviews.

## Technologies Used
- Python
- Django
- Django REST Framework
- React
- JavaScript
- HTML and CSS
- Git and GitHub
- GitHub Actions
- Docker

## Key Features
- User registration, login, and logout
- Display all dealerships
- Filter dealerships by state
- View dealership details and customer reviews
- Submit dealership reviews
- Analyze review sentiment
- Django administration
- Continuous integration and deployment
